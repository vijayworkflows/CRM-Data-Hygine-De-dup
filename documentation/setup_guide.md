# Setup Guide

## Prerequisites
- n8n 2.47.4 or compatible version.
- HubSpot account.
- HubSpot credential with contact read permissions.

## Installation
1. Import the workflow JSON into n8n.
2. Configure your HubSpot credentials.
3. Verify the contact properties.
4. Execute the workflow.
5. Inspect the CSV output.

## Important
Never commit API keys, access tokens, credentials, or real customer data.
